# The environment variables that are credentials.
#
# Which of a deployment's variables are secret is a property of the product, not of the
# deployment, so the product declares it here rather than leaving each operator to judge.
#
# What this is for: a deployment's configuration is two different things in one file today -
# settings an operator edits and credentials they must protect - and the file inherits the
# stricter rule, so none of it can go in a repository. Naming the credentials lets the rest be
# version-controlled, reviewed, and owned by the partner.
#
# A name listed here must not appear in a committable configuration file. `setup_env.py`
# supplies it from a secrets file or from the environment, and refuses to deploy without it.
#
# One name per line. Blank lines and lines starting with # are ignored.

# Databases. Each connection string carries a password.
APPLICATION_MONGODB_URI
USERDATA_MONGODB_URI
TAXONOMY_MONGODB_URI
METRICS_MONGODB_URI
CAREER_EXPLORER_MONGODB_URI
JOBS_MONGODB_URI

# Sign-in.
GCP_OAUTH_CLIENT_ID
GCP_OAUTH_CLIENT_SECRET
ADMIN_FRONTEND_FIREBASE_API_KEY

# The key that encrypts users' personal data. Losing it loses the data; leaking it exposes it.
SENSITIVE_PERSONAL_DATA_RSA_ENCRYPTION_KEY
SENSITIVE_PERSONAL_DATA_RSA_ENCRYPTION_KEY_ID

# LLM providers. A deployment sets the one it uses; the product supports more than one, so a
# credential absent from any given deployment is still a credential.
ANTHROPIC_API_KEY

# Third-party services.
BACKEND_SENTRY_DSN
FRONTEND_SENTRY_DSN
BACKEND_LANGFUSE_PUBLIC_KEY
BACKEND_LANGFUSE_SECRET_KEY
MATCHING_SERVICE_API_KEY
